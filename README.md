# UAV Monitor Russia

Интерактивный дашборд публичных сообщений о фиксациях БПЛА.

## Возможности

- карта опубликованных фиксаций по населённым пунктам;
- история событий 2025-2026;
- объединение сообщений из нескольких источников;
- рейтинг источников;
- фильтры по региону, времени и статусу.

## Структура

- `backend/` — сбор и обработка данных
- `frontend/` — интерфейс карты
- `data/` — конфигурация источников
- `.github/workflows/` — автоматические задачи

Проект показывает только публично опубликованные события и не строит маршруты движения объектов.
